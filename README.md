# Vegavan AI Frontend — Premium Conversational SaaS Marketing & Dashboard

Vegavan AI is a highly sophisticated, editorial-grade Next.js frontend built for creating, training, and managing custom AI website customer receptionists. It features a stunning "Asymmetric Luxury" design language incorporating pure black and zinc tones, high-contrast typography, and modern micro-interactions.

---

## ⚡ Core Pages & Features

### 1. Brand Marketing Pages
-   **Homepage** (`/`): A premium marketing experience featuring interactive chatbot previews, core capabilities grids, and subtle background glow backdrops.
-   **About Page** (`/about`): An editorial overview detailing the core philosophy, technical sandboxing (Shadow DOM), and Webflora Technologies partnership.
-   **Contact Page** (`/contact`): A split-column desk experience with a fully integrated dark-themed contact form and custom validation states.

### 2. Onboarding & Authentication
-   **Login & Signup** (`/login`, `/signup`): standalone dark-glass card portals allowing creators to create accounts or sign in to their dashboards.

### 3. SaaS Dashboard Core (`/dashboard`)
-   **Analytics Overview** (`/dashboard`): Visual charts showing visitor leads and real-time conversation volume over the past 7 days, complete with a pulsing **7-Day Free Trial** active badge.
-   **Knowledge Base Manager** (`/dashboard/knowledge`): Panel to add, list, and edit trained custom documents or FAQs.
-   **Bot Settings** (`/dashboard/settings`): Controls to customize chatbot copy, tone guidelines, and aesthetic themes.
-   **Embed Generator** (`/dashboard/embed`): Easy-to-use utility to generate single-line Shadow DOM script codes for websites.

---

## 🎨 Design Systems & Typography

-   **Typography**: Harmoniously pairs the luxury editorial serif **Cormorant Garamond** (`font-serif-classic`) with the modern sans-serif **Outfit** (`font-sans`).
-   **Color Palette**: Curated monochromatic HSL system (Pure Black, Zinc Grays, and Pure White).
-   **Micro-Animations**: Uses customized sliding fade-ins, hover scaling (`transition group-hover:scale-105`), and pulsing radar dots (`animate-ping`).
-   **Brand Logo**: Incorporates the custom **Speed-Streak Logo Component** (`Logo.tsx`) symbolizing the rapid performance of **Vegavan** (Sanskrit for *speed* / *velocity*).

## 🛠️ Setup & Installation

### 1. Clone & Navigate
```bash
cd Frontend
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` to view the application in your browser.
